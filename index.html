FAQ

What is a JSONL / JSON Lines file?

JSONL is a text format where each line is a separate, complete JSON object. It's widely used for AI and ML datasets, fine-tuning files, and logs, because records can be streamed and appended one line at a time without rewriting the whole file.

Is NDJSON the same as JSONL?

In practice, yes. NDJSON (newline-delimited JSON) and JSON Lines both mean 'one complete JSON object per line'. This tool handles both, and .jsonl, .ndjson and .txt files all work the same way.

How is JSONL different from a normal JSON file?

A JSON file is one single value, often one big array. A JSONL file is many independent JSON objects, one per line, with no surrounding brackets and no commas between records. That's why a standard JSON viewer refuses to open it.

Is my file uploaded anywhere?

No. Everything is parsed in your browser with JavaScript. Your data never leaves your device, which makes it safe for proprietary training sets, private logs and customer data.

Why validate a JSONL file before uploading it?

Training, fine-tuning and bulk-import pipelines parse JSONL line by line, and a single malformed line usually aborts the entire job. Checking first saves a failed — and sometimes billed — run.

What happens if a line is invalid?

Nothing stops. Each line is parsed independently, so the tool keeps going and flags the bad line with its number and the specific JSON parse error. That works in both View and Validate mode, even when most of the file is broken.

What is the key-consistency check?

An optional check in Validate mode that compares each record's top-level keys against the first valid record and flags any that differ. It catches rows with missing or extra fields — lines that are valid JSON but still wrong for your schema.

Can it handle large files?

Yes, within your device's memory. Validation runs over the whole file, and the record list renders in capped batches so the page stays responsive on very large inputs.

Does it work offline?

Yes. Once the page has loaded there are no network calls at all, so both viewing and validation keep working with no internet connection.
